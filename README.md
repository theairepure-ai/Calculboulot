# PLASTI•CALC — application web pour iPhone

## Installation via GitHub Pages
1. Créer un dépôt GitHub public `plasti-calc`.
2. Décompresser cette archive et téléverser **les fichiers à la racine** : `index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`. Ne pas déposer seulement le ZIP.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Attendre le déploiement, ouvrir `https://VOTRE-PSEUDO.github.io/plasti-calc/` dans Safari.
5. Safari > Partager > Sur l’écran d’accueil > Ajouter.

## Fonctionnalités
- 7 machines, jusqu'à 3 vis et 6 doseurs/vis.
- Matières et additifs historiques, ajout/suppression/désactivation.
- OF 536085 chargé comme exemple à 180 kg/h.
- Photo OF et OCR via Tesseract.js (connexion nécessaire), extraction indicative des recettes puis édition manuelle et validation.
- Quantités, débits, temps, bobines, bilan, export/import JSON.
- Sauvegarde locale par navigateur/appareil (pas de synchronisation entre collègues).

**Sécurité :** ne jamais lancer la fabrication sans vérifier les valeurs et références. Les photos de mauvaise qualité peuvent être mal lues.
